YOUR TANDY HAS ANOTHER SCREEN

PROPOSED FOR NOVEMBER 2026. Not part of the tested October issue.

Read ARTICLE.TXT. Use SCREEN 1, SCREEN 2 or SCREEN 3.
SCREEN alone runs all three brief original demonstrations.
1 Palette cycling / 2 Tearing vs page flip / 3 Retrace palette split.
Space = next demo. Escape or Ctrl-C returns to DOS. Demo 2: T switches
tear/clean. Demo 3: Up/Down move the split line.
Plain DOS on a known-compatible Tandy only. No driver, nothing resident.
The screen clears to the original text mode on exit.

SCREEN.EXE was built with Microsoft C 6 /G0 /AS /Os and MS LINK 3.64.
Host checks on the helper code and DOSBox-X (Tandy machine) runs passed.
